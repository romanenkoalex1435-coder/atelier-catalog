# REWEAR VINTAGE — витрина одежды

Статический каталог и корзина с отправкой заявки продавцу через Telegram. Оплата и доставка обсуждаются в переписке. Telegram-бот управляет товарами через коммиты в GitHub; подключённый к репозиторию проект Vercel публикует обновления автоматически.

## Что работает

- Категории, выбор размера, корзина с сохранением в браузере.
- Серверная проверка товара, размера, количества и цены перед отправкой заказа.
- Сообщение продавцу с контактом покупателя, размерами и ссылками на товары.
- Команды Telegram-бота `/add`, `/edit`, `/delete`, `/hide`, `/show`, `/list`.
- Фото к новому товару можно приложить к сообщению `/add`; изображение сохраняется в репозитории.

Сейчас каталог содержит демонстрационные позиции. Перед продажами замените их настоящими товарами и укажите название магазина и Telegram продавца.

## Развёртывание

1. Создайте GitHub-репозиторий и загрузите этот проект в корень. Подключите репозиторий к Vercel как проект с фреймворком **Other**. Build command и output directory оставьте пустыми.
2. Через [@BotFather](https://t.me/BotFather) создайте бота и получите токен. Продавец должен первым написать боту `/start`.
3. Узнайте числовой Telegram ID продавца и задайте переменные Vercel из `.env.example`. `GITHUB_TOKEN` должен иметь доступ **Contents: Read and write** только к этому репозиторию. `TELEGRAM_WEBHOOK_SECRET` задайте случайной строкой. Не коммитьте секреты.
4. В `config.json` укажите публичный Telegram username продавца без `@`. В `PUBLIC_SITE_URL` укажите адрес Vercel без завершающего `/`.
5. После деплоя зарегистрируйте webhook (подставьте значения локально, не публикуйте токен):

   ```bash
   curl -X POST "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/setWebhook" \
     --data-urlencode "url=${PUBLIC_SITE_URL}/api/telegram" \
     --data-urlencode "secret_token=${TELEGRAM_WEBHOOK_SECRET}"
   ```

6. Отправьте боту `/help`, затем добавьте реальные товары. Удалите демонстрационные позиции через `/delete ID` или измените `data/products.json` вручную.

## Формат команд

Отправьте боту фотографию с подписью:

```text
/add Куртка оверсайз | 6900 | Верхняя одежда | S, M, L | Состояние отличное
```

Другие команды: `/edit ID | Название | Цена | Категория | Размеры | Описание`, `/hide ID`, `/show ID`, `/delete ID`, `/list`.

## Локальная проверка

```bash
npm test
npm run check
python3 -m http.server 4173
```

Статический сервер показывает витрину, но функции `/api/*` работают только в Vercel или при локальном запуске Vercel CLI. Для приёма реальных заявок нужны настроенные переменные окружения.
