# REWEAR VINTAGE — витрина одежды

Статический каталог и корзина. Заказ: кнопка открывает чат продавца в Telegram с готовым списком вещей. Данные покупателей не собираются, оплаты на сайте нет. Товары правятся в админ-панели `/admin/`: она коммитит изменения в GitHub, Vercel публикует их автоматически.

## Админ-панель

Адрес: `https://<сайт>/admin/`. Можно добавить вещь с несколькими фото (до 8, первое на обложке, порядок меняется стрелками), отметить дефекты на фото, поставить «Бронь», отметить «Продано», скрыть, показать и удалить.

### Вход
- Первый вход по **временному логину и паролю**: сразу после него админка попросит придумать свой логин и пароль (не короче 12 символов). Временный после этого перестаёт работать.
- Сменить логин, пароль и ограничения по IP можно в любой момент: кнопка **«Аккаунт»**. Для изменений нужен текущий пароль. После смены пароля другие устройства выходят из админки.
- **Защита по IP:** после 5 неверных попыток подряд вход с этого IP блокируется на 15 минут. В «Аккаунте» можно включить «Пускать только с этих IP» (точный адрес или диапазон `85.140.*`). Сохранить список без вашего текущего IP нельзя, чтобы не потерять доступ.
- Пароль хранится только в виде хеша (scrypt), сессия — 12 часов в cookie `HttpOnly; Secure; SameSite=Strict`.

### Где хранятся данные входа
- На своём сервере (`STORAGE=fs`): `DATA_DIR/private/admin.json`, доступен только серверу, наружу не отдаётся.
- На превью Vercel: `private/admin.json` в репозитории (исключён из публикации `.vercelignore`), сервер читает и меняет его через GitHub. Для этого в Vercel нужен **только `GITHUB_TOKEN`** (fine-grained, этот репозиторий, Contents: Read and write); репозиторий Vercel берёт сам.
- Старый способ через переменные `ADMIN_LOGIN`, `ADMIN_PASSWORD_HASH`, `ADMIN_SESSION_SECRET` работает, если файла нет.

### Если доступ потерян (забыт пароль, заблокировал IP-список)
`node scripts/reset-admin.mjs` — создаёт новый временный пароль (на сервере: `DATA_DIR=/var/rewear node scripts/reset-admin.mjs`; для превью — закоммитить обновлённый `private/admin.json`).

## Превью товаров без фона (автоматически в админке)

Когда вы добавляете вещь и загружаете первое фото на ковре, админка сама вырезает вещь: прямо в вашем браузере, ничего не отправляется наружу. Результат показывается рядом с оригиналом. Дальше:
- если замечаний нет, превью принимается сразу, вы проверяете глазами и нажимаете «Сохранить»;
- если проверка нашла проблему (потерянная деталь, «дыра», вещь не найдена), нужно решить: «Всё равно использовать» или «Оставить фото на ковре»;
- можно загрузить своё превью (PNG или WebP) или нажать «Вырезать заново» с другим «Типом вещи» (он задаёт масштаб в кадре).

Одна вырезка занимает около 10 секунд. Первый раз скачивается модель (≈45 МБ), потом она берётся из кэша браузера. Модель ISNet (Apache-2.0, `models/`) и движок onnxruntime-web (MIT, `vendor/ort/`) лежат в репозитории. Качество честное, но не идеальное: на тёмных вещах и на краях иногда остаются мелкие кусочки ковра, поэтому сравнивать с оригиналом нужно всегда. Для особенно сложных вещей остаётся скрипт `scripts/make-preview.py` (модель BiRefNet, чище, запускается на компьютере с Python).

## Превью ссылок

Ссылки на вещи в сообщении заказа имеют вид `https://<сайт>/p/<id>`: функция `api/share.js` отдаёт Open Graph с фото и ценой и перекидывает человека в каталог. В `index.html` у `og:image` указан адрес `https://atelier-catalog.vercel.app/og.jpg`; при подключении своего домена замените его там.

## Перенос на российский хостинг

Vercel нужен как превью для заказчика. Для постоянного хостинга есть обычный Node-сервер: он отдаёт сайт и работает с админкой, а вещи и фото хранит на диске сервера (без GitHub).

Нужен VPS с Node.js 20+ (Timeweb Cloud, Selectel, REG.RU, Beget VPS и т. п.) и домен.

1. Скопируйте проект на сервер, например в `/opt/rewear`.
2. Создайте папку данных и перенесите текущий каталог: `mkdir -p /var/rewear && cp -r data images /var/rewear/`.
3. Создайте `/opt/rewear/.env` по образцу `.env.example`: `STORAGE=fs`, `DATA_DIR=/var/rewear`, `PORT=3000`, `PUBLIC_SITE_URL=https://ваш-домен`, `TRUST_PROXY=1` (сервер за nginx). Перенесите вход: `cp -r private /var/rewear/` или создайте новый временный `DATA_DIR=/var/rewear node scripts/reset-admin.mjs`.
4. Запустите как службу: `deploy/rewear.service` (systemd), перед ним nginx с HTTPS: `deploy/nginx.conf`. HTTPS обязателен: без него cookie входа в админку не работает.
5. Замените адрес `atelier-catalog.vercel.app` на свой домен в `index.html` (`og:image`) и `robots.txt` (`Sitemap:`).
6. Резервные копии: достаточно регулярно копировать папку `DATA_DIR` (каталог и фото).

Проверка локально: `STORAGE=fs DATA_DIR=. PORT=3000 node server.mjs` и открыть `http://localhost:3000`. Сервер отдаёт только файлы сайта: код, тесты, `.env` и `.git` закрыты. Персональные данные покупателей сайт не собирает.

## Настройка

- `config.json`: `sellerTelegram` — username продавца без `@`; `telegramChannel` — username канала для ссылки в подвале (пусто — ссылки нет); `yandexMetrika` — номер счётчика Яндекс Метрики (пусто — аналитики нет). Счётчик загружается только после согласия посетителя в плашке cookie.
- `data/products.json`: каталог (меняется админкой). Демо-товары с пометкой «Пример» удалите в админке.

## Локальная проверка

```bash
npm test
npm run check
python3 -m http.server 4173
```

Статический сервер показывает витрину. Админка и `/api/*` работают только в Vercel или через Vercel CLI (`vercel dev`) с переменными окружения.
