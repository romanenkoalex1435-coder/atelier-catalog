# REWEAR VINTAGE

Витрина одежды, корзина и заказ через Telegram. Магазин и админка работают на PHP 8.2+ на Reg.ru Host-0: https://rewearvintage.shop и `/admin/`. Каталог и фотографии сохраняются на диске хостинга, изменения товаров видны сразу.

## Сборка

`npm run build` собирает `dist-reg/`: витрину, админку, PHP API, модель вырезания фона и движок ONNX. Node.js нужен только для подготовки файлов на компьютере или в CI. Сайт обслуживает PHP; внешние сервисы публикации ему не нужны.

Сборка не содержит каталог, загруженные фотографии и настройки входа. Они размещаются отдельно в `REWEAR_DATA_DIR` вне корня сайта. Для начального переноса скопируйте туда `data/` и `images/` из проекта. Никогда не перезаписывайте эти папки при обновлении кода.

## Хостинг

Корень сайта: `/var/www/u3675365/data/www/rewearvintage.shop`.
Данные: `/var/www/u3675365/data/rewear-data`.

Перед публикацией сохраните резервную копию корня сайта и папки данных. Загрузите содержимое `dist-reg/`, включая `.htaccess`, в корень сайта. Настройки `REWEAR_SITE_URL=https://rewearvintage.shop` и `REWEAR_DATA_DIR` задаются через закрытую конфигурацию PHP или переменные окружения веб-сервера. Закрытые настройки и резервные копии находятся вне `www/`.

Вход в админку требует действующий HTTPS-сертификат. Cookie сессии защищена HttpOnly, Secure и SameSite=Strict. Настройки входа не публикуются в репозитории. При переносе со старого Node.js допускается миграция scrypt-хеша; после успешного входа пароль получает PHP-хеш. Старый секрет сессии нужно заменить.

## Проверка

`npm run check` проверяет JavaScript. PHP-файлы проверьте командой `php -l`. HTTP-интеграционные проверки в `test/` запускайте на отдельной копии данных, а не на рабочем каталоге.

## Резервные копии

Регулярно архивируйте всю папку данных: `data/products.json`, `images/`, `private/`. Храните несколько копий вне корня сайта. Восстанавливайте каталог и фотографии вместе, из одной резервной копии.

## Настройки

`config.json`: Telegram продавца, канал, адрес сайта и необязательный счётчик Метрики. Метрика загружается после согласия посетителя. Оплата на сайте и сбор персональных данных покупателей не добавлены.

Фото, заметки о деталях/дефектах, бронь, продажа, скрытие и удаление редактируются в существующей админке. Вырезание фона работает в браузере с локально размещённой моделью и не отправляет фотографии внешнему сервису.
