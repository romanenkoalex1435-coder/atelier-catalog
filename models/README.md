# Модель вырезки фона

`isnet-general-use.int8.onnx`: ISNet (DIS, https://github.com/xuebinqin/DIS), лицензия Apache-2.0, квантованная до int8 (≈44 МБ, маска совпадает с оригиналом на 99,9%). Запускается в браузере админки через onnxruntime-web (MIT, `vendor/ort/`). Файлы отдаются с вашего же сайта: внешних сервисов нет, фото не покидают браузер.
