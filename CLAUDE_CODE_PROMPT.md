# Промпт для продолжения работы

Проект: витрина винтажной одежды **REWEAR VINTAGE**. Продавец в Telegram: `@iamozwe`. Сначала прочитай `README.md`, `DESIGN_SYSTEM.md` и код.

Живой сайт: https://atelier-catalog.vercel.app (Vercel, деплой автоматически с `main`). Репозиторий приватный.

## Как устроено сейчас
- Статика без сборки: `index.html`, `styles.css`, `app.js`, `paper.js`. Каталог: `data/products.json`, конфиг: `config.json` (`sellerTelegram`).
- Каталог без категорий и без размеров: каждая вещь в единственном экземпляре. Плитка открывает лист товара, «Добавить в корзину» кладёт вещь (количество всегда 1).
- **Заказ:** кнопка «Написать в Telegram» открывает `t.me/<seller>?text=…` с готовым списком вещей и ссылками `/?product=<id>`. Данные покупателя не собираются, оплаты нет.
- **Дизайн:** светлая молочная состаренная бумага. Фон рисует шейдер WebGL (`paper.js`): мятая бумага, свет за курсором, параллакс, старение. Подробности в `DESIGN_SYSTEM.md`. Apple-механика: листы на пружинах, смахивание, reduced-motion. Анимации: заголовок по буквам, проявление плиток, наклон карточки, полёт вещи в корзину.
- **Админ-панель** `/admin/` (`admin/*`, `api/admin/{login,logout,products}.js`, `lib/auth.js`, `lib/github.js`): логин/пароль, подписанная cookie, CRUD товаров и фото через GitHub Contents API. Env: `ADMIN_LOGIN`, `ADMIN_PASSWORD_HASH`, `ADMIN_SESSION_SECRET`, `GITHUB_TOKEN`, `GITHUB_REPO`. Хеш генерирует `scripts/hash-password.mjs`.
- **Витрина (текущая версия):** тёплое молоко `#DDD4C0`, цвета ковра (акцент `#9D3320`), логотип «Rewear» шрифтом Caprasimo (лежит в `fonts/`) на фото ковра `images/hero.webp` с зерном (SVG-фильтр `#aged`), красная бегущая строка, заголовки `Catalog/Archive/Cart/Say hi` тем же шрифтом. Каталог: фильтры по эпохе и бренду, сортировка, бирка с ценой, галерея до 8 фото, метки двух типов (деталь/дефект), статусы «Бронь» и «Ушло» (архив). Описание в `DESIGN_SYSTEM.md`. Старый заказчик отверг холодный чёрный и тёмную тему; цвета держать в палитре.
- **Автовырезка в админке:** `admin/cutout.js` (ISNet int8 из `models/`, onnxruntime-web из `vendor/ort/`, потоки выключены: с ними вырезка зависала). Живой Vercel не проверялся.
- **Превью товаров:** вырезки `images/preview/*.webp` (скрипт `scripts/make-preview.py`, BiRefNet); у вещи без `preview` или с отбракованной вырезкой (демо Wrangler: потерялась бирка в вороте) в каталоге оригинал. Подробности в `DESIGN_SYSTEM.md`.
- **Превью ссылок:** `/p/<id>` (`api/share.js`, rewrite в `vercel.json`) отдаёт Open Graph. В `index.html` `og:image` захардкожен на `atelier-catalog.vercel.app`.
- Telegram-бота больше нет: ни кода, ни webhook, ни переменных. Telegram остаётся только как чат продавца для заказа.

## Состояние сервисов
- GitHub и Vercel подключены. Деплои идут с `main`. Vercel блокирует деплой, если автор коммита не связан с аккаунтом: коммитить с автором `<id>+romanenkoalex1435-coder@users.noreply.github.com`.
- **Админка не проверена на реальных сервисах.** Нужно, чтобы владелец сам задал в Vercel `ADMIN_LOGIN`, `ADMIN_PASSWORD_HASH`, `ADMIN_SESSION_SECRET`, `GITHUB_TOKEN`, `GITHUB_REPO` (см. README). Не проси пароли и токены в чат.
- В Vercel остались лишние переменные старого бота (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_OWNER_ID`, `TELEGRAM_WEBHOOK_SECRET`, `PUBLIC_SITE_URL`): их можно удалить, а токен бота отозвать в @BotFather (`/revoke`), потому что он светился в чате. Webhook можно снять (`deleteWebhook`).
