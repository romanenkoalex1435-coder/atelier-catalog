# Промпт для Claude Code

Продолжи работу над проектом витринного сайта одежды в этой папке. Пользователь просил каталог по категориям, выбор размера и корзину, отправку заказа продавцу в Telegram, управление товарами через Telegram-бота, GitHub-репозиторий и деплой на Vercel. Пользователь остановил текущую работу из-за лимита и попросил передать состояние. Сначала прочитай `README.md` и код, затем проверь проект и доведи до публикации после получения доступов и данных продавца.

## Что уже сделано

- Статическая адаптивная витрина: `index.html`, `styles.css`, `app.js`.
- Фильтрация по категориям, размеры, корзина в `localStorage`, форма заявки.
- `api/order.js` проверяет товар, размер и цену на сервере и отправляет заказ продавцу через Telegram Bot API. При настройке `config.json` покупателю показывается ссылка на Telegram продавца.
- `api/telegram.js` принимает webhook только с секретным заголовком и от указанного Telegram ID продавца. Команды `/add`, `/edit`, `/delete`, `/hide`, `/show`, `/list`. При добавлении можно приложить фото; каталог и фото сохраняются коммитами через GitHub Contents API.
- Демо-каталог `data/products.json`, конфигурация `config.json`, `.env.example`, инструкции `README.md`.
- Локальный Git-репозиторий и тесты. Последняя проверка: `npm test` — 8/8, `npm run check` — успешно. В браузере проверены загрузка каталога, добавление товара в корзину и отображение корзины. Живая отправка заказа и работа webhook ещё не проверялись: нет токенов и деплоя.

## Что осталось

1. Уточнить у пользователя название магазина, публичный Telegram username продавца, Telegram ID, реальные товары/фото и условия. Название «Линия» и шесть товаров сейчас демонстрационные.
2. Проверить и при необходимости исправить UX и серверную часть, особенно полный заказ, ошибки, мобильный экран, работу команд бота и автоматическое обновление сайта после коммита каталога. Локальный Python HTTP-сервер не обслуживает `/api/*`; для интеграционной проверки нужен Vercel dev/preview.
3. Создать GitHub-репозиторий, запушить проект и подключить Vercel. На момент передачи `gh auth status` показывал **недействительный токен** аккаунта `romanenkoalex1435-coder`; GitHub и Vercel в браузере открывали страницы входа. Пользователь сказал, что авторизуется позже. Не запрашивай пароли или токены в чат.
4. После подключения репозитория добавить секреты в переменные Vercel по `.env.example`, зарегистрировать Telegram webhook согласно `README.md`, проверить реальный заказ и команды бота. Токен GitHub должен иметь минимальный доступ `Contents: Read and write` только к новому репозиторию. Бот должен получать сообщения от владельца после его `/start`.
5. Удалить или заменить демо-товары перед настоящими продажами. Договорённость об оплате и доставке остаётся в Telegram; платёжной интеграции нет.

Проверь текущий Git-статус. Код не опубликован на GitHub и не задеплоен в Vercel. Не называй интеграцию готовой без проверки на реальных настроенных сервисах.
