# Промпт для продолжения работы

Проект: витрина винтажной одежды **REWEAR VINTAGE**. Продавец в Telegram: `@iamozwe`. Сначала прочитай `README.md`, `DESIGN_SYSTEM.md` и код.

Живой сайт: https://atelier-catalog.vercel.app (Vercel, деплой автоматически с `main`). Репозиторий приватный.

## Как устроено сейчас
- Статика без сборки: `index.html`, `styles.css`, `app.js`, `paper.js`. Каталог: `data/products.json`, конфиг: `config.json` (`sellerTelegram`).
- Каталог без категорий и без размеров: каждая вещь в единственном экземпляре. Плитка открывает лист товара, «Добавить в корзину» кладёт вещь (количество всегда 1).
- **Заказ:** кнопка «Написать в Telegram» открывает `t.me/<seller>?text=…` с готовым списком вещей и ссылками `/?product=<id>`. Данные покупателя не собираются, оплаты нет.
- **Дизайн:** светлая молочная состаренная бумага. Фон рисует шейдер WebGL (`paper.js`): мятая бумага, свет за курсором, параллакс, старение. Подробности в `DESIGN_SYSTEM.md`. Apple-механика: листы на пружинах, смахивание, reduced-motion. Анимации: заголовок по буквам, проявление плиток, наклон карточки, полёт вещи в корзину.
- `api/telegram.js` и `lib/*`: webhook бота для управления товарами (`/add /edit /delete /hide /show /list`), коммиты в каталог через GitHub Contents API. **Бот пока просит размеры, а на сайте их нет: нужно убрать.**
- `api/order.js` с тестами остался от старой схемы и сайтом не используется: можно удалить.

## Состояние сервисов
- GitHub и Vercel подключены. Деплои идут с `main`. Важно: Vercel блокирует деплой, если автор коммита не связан с аккаунтом. Коммитить с автором `<id>+romanenkoalex1435-coder@users.noreply.github.com`, не с локальным `@MacBook-Pro.local`.
- В Vercel (Production) заданы: `TELEGRAM_BOT_TOKEN` (бот @vitrina_korolya_bot), `TELEGRAM_OWNER_ID`, `TELEGRAM_WEBHOOK_SECRET`, `GITHUB_REPO`, `PUBLIC_SITE_URL`. **Нет `GITHUB_TOKEN`:** без него бот не сможет сохранять товары. Токен создаёт владелец (fine-grained, `Contents: Read and write`, только этот репозиторий) и добавляет сам. Не проси токены и пароли в чат.
- Webhook зарегистрирован на `/api/telegram`. Работа бота и живой заказ на реальных сервисах **не проверялись**.
- Токен бота светился в чате: предложить владельцу перевыпустить в @BotFather (`/revoke`) и обновить в Vercel.
